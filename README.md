
# Pet Hotel Booking App
Сервис, предоставляющий возможность вести учет номеров, 
постольцев и бронирований для зоо-отелей.

### Требования

- JDK 17 и позднее

### Примечания

Для сохранения компактности и удобства работы с репозиторием, **jar-файлы и большие файлы не хранятся в репозитории**. Если вам необходимо работать с такими файлами, используйте [Git LFS](https://git-lfs.github.com/) или храните их отдельно.

### Примечания

Чтобы сохранить компактность и удобство работы с репозиторием, **jar-файлы и большие файлы не хранятся в репозитории**. Jar-файлы уже добавлены в `.gitignore`, но для дополнительной надёжности рекомендуется использовать [Git-хуки](#настройка-pre-commit-хуков), чтобы предотвратить их случайное добавление.


### Настройка pre-commit хуков

Чтобы предотвратить случайное добавление jar-файлов и файлов большого размера, выполните из корневой директории проекта:

```bash
cp dev-tools/hooks/pre-commit .git/hooks/pre-commit
```
```bash
chmod +x .git/hooks/pre-commit
```
